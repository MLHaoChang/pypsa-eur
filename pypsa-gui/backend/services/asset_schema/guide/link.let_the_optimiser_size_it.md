## What it means

Tick this to let the optimiser decide how big the link should be, anywhere between the smallest and largest size you set. For every MW it adds, the annualised cost is charged to the plan. Leave it unticked to treat the size as fixed. Use it when you are asking how much to build rather than testing a design you already have.

## Example

Tick it on an electrolyser to let the optimiser pick between 0 and 3 MW.
