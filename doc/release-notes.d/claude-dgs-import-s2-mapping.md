* Feat(gridspine): PowerFactory DGS import, step 2: a ``.dgs`` export becomes a network (``gridspine/ingest/dgs_import.py``, format ``dgs`` in the import registry). Terminals and closed couplers, lines, two- and three-winding transformers (off-nominal ratios and taps as pandapower models them), loads, static generators, synchronous machines, external grids with both short-circuit cases, shunts and harmonic spectra are mapped; every other item is listed as not imported, every assumed value as assumed, and impossible values refuse the import naming the item.
