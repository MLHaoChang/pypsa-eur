* Feat(pypsa-gui): The assistant can change a set of assets in one card: "increase all solar capacity by 20 %" selects by carrier, bus or class, and the server resolves the set and computes every new value (scale factors only, 0 < f ≤ 1000). The set is frozen at preview time: an asset added before apply makes the apply refuse.
