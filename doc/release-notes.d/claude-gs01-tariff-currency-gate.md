* Fix(pypsa-gui): A tariff now carries its ISO 4217 currency (stated, or taken from its jurisdiction; a Library tariff whose jurisdiction implies none must state it), and a tariff in another currency than the project's finance currency is refused (`currency_mismatch`, nothing converted) at attach and in preflight. The currency stays out of the canonical hash, so shipped and stored Library pins keep resolving. An existing project whose finance currency is EUR (the default included) and whose tariff is in another currency now gets this preflight error until its finance currency is set.
