* Fix(gridspine): The campus library's 220/110 kV transformers (TR_220_110_125 to TR_220_110_315) take their load and no-load losses from OPTCL's 220/132 kV autotransformer maximum permissible losses (a tender cap; Technical Specification for Power and Auto Transformers, Rev. 1, May 2025). The units are assumed to be autotransformers, so the losses are scaled by 1.25, and every value stays tagged `assumed`; a two-winding unit would lose roughly 2-2.5x as much. This replaces the class rule, which missed the Ecodesign Tier 2 efficiency minimum. Defaults pack version 2026-11-13 pins the new library.
