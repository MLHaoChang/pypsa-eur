* Feat(pypsa-gui): The in-app assistant's per-chat event log is now the conversation's source of truth. What the model is sent each turn is built from it (secrets redacted, as in the saved chat history), a chat the server no longer holds in memory, for example after a restart, comes back with its tool calls and results instead of only the text, and an interrupted message is detected from the log (the separate `chat.jsonl.pending` file is gone).
