* Feat(pypsa-gui): Values from a PDF without the chat (data-to-model slice 2). The asset tables' "Import values from a file…" (formerly "Import rows from a table…") now also takes a PDF datasheet: you pick the assets the values are for, and for each field the dialog lists the lines of the document that state a value with one of its units, grouped by page, to tick at most one each. The preview is the same edit card as the assistant's, with each value's page and quote. In Commercial & parties, the Import tariff and Contracts blocks get "Fill values from a PDF…", which opens the same dialog for the tariff's rates or a PPA contract's values; a tariff or contract pinned to the Commercial library links to the library instead.
