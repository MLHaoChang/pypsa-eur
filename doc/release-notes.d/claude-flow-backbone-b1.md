* Feat(pypsa-gui): Project flow backbone. `GET /api/projects/{name}/flow` files the existing checks (the run preflight, the Energy Hub readiness, the project's bind issues, a template's assumed defaults and a few presence rules) into the ten flow sections, from Project & site to Results, each `complete`, `warning`, `incomplete` or `not_needed`, with `run_ready` and the first blocker; `POST …/flow/ack` acknowledges a warning until its value changes. Assistant workflow steps name their flow section. No UI yet.
