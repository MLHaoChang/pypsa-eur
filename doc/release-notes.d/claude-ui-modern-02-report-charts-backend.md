* Feat(pypsa-gui): Charts saved from Results can now be kept for the study report. The new `/api/projects/{name}/report-charts` routes store a chart's picture and its table (up to 12 per project), and a report written from the Reports panel adds them in a "Charts from Results" section with the time they were shown and a note when they come from an earlier solve. Reports written by the assistant carry no saved charts.
