* Feat(pypsa-gui): Durable assistant conversations refuse to run under more than one application worker (`503 multi_worker_unsupported`). Each worker holds an exclusive lock on the conversation store it serves, so a second worker is refused however it was started. The worker count from the desktop launcher, `--workers` / `-w` or `WEB_CONCURRENCY` gives an earlier refusal. A deployment smoke procedure is in `pypsa-gui/docs/live-voice-deployment-smoke.md`.
