* Feat(pypsa-gui): Study harness runs get a data-centre profile, `eh_datacenter@1`. The run is held to one published grid-code profile, frozen with its id, label and digest. If that profile is republished, the run stops and waits for the user. The runner itself runs the campus study and the grid-readiness read. The result gate scores each scorecard row by verdict: a block row never passes on assumed inputs, a warn row with a missing input reads "not evaluated", and ride-through and dynamic rows never pass.
