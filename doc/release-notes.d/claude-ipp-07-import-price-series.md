* Feat(pypsa-gui): a wholesale-indexed import price, `CommercialConfig.import_price_ref`. It is a Library series written on the import Link(s), added to the import side of the optimisation (so a battery charges from the grid at day-ahead), and persisted in the solve's energy-price record, so the cost rows carry it after a reload. The value-flow ledger books it as its own stream, `energy_wholesale` (site to market, escalated with the market like export), apart from the tariff, and the reconciliation still closes. Preflight's arbitrage check includes it. The tariff editor gains a "Prices the optimisation uses" block with Library pickers for the export and the import price series, with their provenance. Configs without the import price are unchanged.
