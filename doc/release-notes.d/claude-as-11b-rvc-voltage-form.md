* Feat(pypsa-gui): The grid-readiness rapid-voltage-change row and its after-battery value now use the voltage form (cos ψ·ΔP + sin ψ·ΔQ)/S_k (IEC TR 61000-3-7). It reads the AI-training envelope's tan φ_swing and the PoC X/R, which for now is the assumed 4. While that X/R is assumed, a pass also needs the X/R-free bound √(ΔP²+ΔQ²)/S_k under the limit; otherwise the row warns and shows that bound. Verdict change: with X/R assumed, the warn threshold moves from a real swing of 3 % of S_k to 3/√(1 + tan²φ) % (2.985 % at tan φ 0.1). Values now include the reactive swing, so a near-zero after-battery change reads about 0.9 % at tan φ 0.1. The row is always marked assumed.
