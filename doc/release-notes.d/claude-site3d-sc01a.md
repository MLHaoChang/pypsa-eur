* Feat(pypsa-gui): Backend for the native Site 3D scene (no UI yet). A project can store confirmed site coordinates (`GET/PUT /api/projects/{name}/site-anchor`, revision-checked). A Site can be explicitly adopted into a 3D scene, which then keeps immutable revisions behind one pointer. Native buildings are previewed as proposals and applied with a revision check, needing no Bus or network change. The project `/flow` gains an additive `scene` block of Site 3D verdicts, listing the Sites that lie more than 1 km from the site coordinates; its existing keys are unchanged. A whole-document `PUT /sites` that would overwrite an adopted Site is refused (`scene_managed_site`). Snapshots, scenarios, Save-As and bundle export carry only an adopted Site's current scene revision. Renaming or deleting a component re-keys or drops its placement and footprint in the scene.
