* Feat(gridspine): Grid-code profiles can hold the requirement shapes of SAGC-type codes (Saudi Arabian Grid Code, May 2026), all optional with no default: an infrequent rapid-voltage-change tier `rvc_limit_infrequent_pct` beside `rvc_limit_pct` (the frequent tier, unchanged), a P-dependent Q band at the connection point `q_capability_pq` (points `[p_pu, q_min_pu, q_max_pu]`, interpolated linearly), asymmetric power-factor limits `pf_min_lagging` and `pf_min_leading`, and a `kind` and `unit` on dynamic requirements, which the report lists as "needs RMS study", never judged. The campus compliance report gains `pcc_q_band` and `pcc_power_factor` (hours with |P| below 10 % of P_ref left out of the power factor), the grid-readiness scorecard a `rapid_voltage_change_infrequent` row (connection capacity / fault level × 100), and a check whose limit the profile does not set reads `unknown` ("no limit set"), never pass or fail, and leaves the "checks pass" count. The grid-code review table shows the new limits.
