* Feat(pypsa-gui): Solve committable process units (Links with `eh_process`). A planning solve runs PyPSA's linearised unit commitment for them (the new solver setting `process_uc`: `auto`, `linearised` or `binary`; `auto` stays binary when other units are committable). After a linearised plan, a binary operational check re-solves the first 168 snapshots of each period with capacities fixed. It reports binary minus linearised cost and the extra shortfall per period at `GET /api/results/process_uc_check`, and flags more than 2 % cost or any extra shortfall as "linearised UC understates restarts". The MIP gap and time limit now also apply when only a Link is committable. The solver warns about a start-up or shut-down cost on a weighted network, which PyPSA leaves unweighted. The template build refuses that case, a committable and extendable process unit, a missing lost-production value, a lost-production value set to VoLL, and one priced at or below the buy-in price. Networks without process units solve exactly as before.
