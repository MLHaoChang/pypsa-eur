* Feat(pypsa-gui): A carrier has a Properties card: clicking a row of the Carriers table opens it, with the display name, colour, unit and CO₂ intensity taken from the asset schema, and an edit form that can rename the carrier. Solver Settings' global constraints are added and edited through one form built from the same schema; each constraint type shows only the fields it uses, and an existing constraint can now be edited in place instead of deleted and re-added.
