* Fix(pypsa-gui): FMEA criticality is now per year on every horizon. Class A (COPT, including per-period blocks and common-mode events) and class B (Link sweep) scale the horizon's ΔEUE × VoLL by 8760 / Σ snapshot weights, matching the annual occurrence, so severity (criticality / occurrence) no longer mixes a per-horizon and a per-year figure. Class C stress scenarios stay per event (the event lasts the modelled horizon) and note when their events overlap the year. Each failure mode states `criticality_basis` and `horizon_years`; Energy Hub reports saved before this change are marked as per horizon in the panel, the report table and the Pareto figure.
