* Feat(pypsa-gui): Report comments become revisions (study harness 07c). A comment on one paragraph, bullet list or table of a saved report is kept until it is addressed or withdrawn. It is addressed by an edit from a closed set (paragraph or bullet text, table caption and headers, table number formats), saved as a new version against the latest version's digest. An edit that would change a number, disclosure, evidence reference, figure or the number audit is refused, and the comment stays open with its reason.
