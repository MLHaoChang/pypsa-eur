* Feat(pypsa-gui): Every Energy Hub template ships the finance inputs its investment case needs, so a new project gets a first NPV without hand inputs. The data-centre campus gains a point of connection, owners, dates and finance inputs, and its existing assets are typed as sunk. Every template gains a stand-in tax rule (German corporate tax, Hebesatz 400 %) and depreciation classes from the BMF AfA table. Each shipped value is recorded with its source; GET /api/simulation/finance and the assistant name them as assumed until the user changes them.
