* Feat(pypsa-gui): Assistant memory, reusable parameters (backend): an asset field's saved value can be kept for reuse (the server reads the value, unit, carrier and money stamp from the project), offered again for the same field in later projects of the same organisation, and applied only through an old → new card the user approves. An applied value is stamped `memory:<id>@v<n>` in its provenance and can be undone; a vanished field, another unit (a value saved on a bus that counts in t/h stays in t/h), currency, money year or carrier, or a field set by a time series is refused, and nothing is converted.
