* Feat(pypsa-gui): The investment case can now compare a site whose own conversion serves a non-electric load (an electrolyser feeding an H2 offtake) against buying that load instead. A `reference_purchases` entry in the commercial config (price per kg, energy per kg, CO2 per kg, source) lets the comparison buy, say, grey hydrogen, where it was refused before (`owner_conversion_load`). An optional `co2_price` (real prices by year) adds the certificate cost of that purchase and, when a grid intensity is set, of grid imports on both sides, so only the difference counts. A period before the first priced year is refused rather than extrapolated. The avoided CO2 cost is shown separately in the report and the workbook, and both new caveats appear beside the headline figures. Cases without these inputs are unchanged.
