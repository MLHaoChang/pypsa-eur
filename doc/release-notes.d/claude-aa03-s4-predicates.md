* Feat(pypsa-gui): A checked answer can state that all, or none, of a component class meets a threshold, or name its top k (every tie at the boundary included, labelled with the count). The software decides the truth and the members from one complete, current page of configured inputs read in the same turn; a partial page, an uncertified row, an empty class, a unit other than the metric's own, a k larger than the class, or a claim that disagrees with the software limits the answer.
