* Feat(pypsa-gui): Super-admins can add, edit, test and remove MCP servers that use a URL in Settings → External tools. Each server's bearer token is stored like the assistant's LLM keys and never shown. Servers that run a local command are listed, tested and keyed there but are still edited only in `mcp-servers.json`. Redirects are never followed, and a server's environment may not set loader or interpreter variables (`LD_*`, `DYLD_*`, `PYTHON*`, `NODE_OPTIONS`, `PATH`, `HOME`, `SHELL`). A confirmation card for an external tool names its server, and the `run_chat_smoke.py --workflow` parity battery checks that a read-only external tool runs without a card and a write tool asks first.
