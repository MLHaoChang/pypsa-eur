* Feat(pypsa-gui): A harness run with a granted approval envelope now repairs a failed input gate by itself. It runs up to three headless agent rounds, each offering only the stage's allowed tools. A data gap such as a load with no demand series is filled only where none is set, and only from a source fixed when the envelope was granted: a load keeps its own annual energy, and the weather and tariff come from the profile's list or the tariffs already held. The agent may change only the attributes the failed rules name. Each verified change is written to the run's change ledger, and rounds and tokens are counted in the run budget. A round that makes no progress or runs out of budget hands the run back to the user (study harness issue 04).
