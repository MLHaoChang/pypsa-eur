* Feat(gridspine): The PSS/E import reads a `.dyr` dynamic data file and a `.con` contingency file alongside the `.raw` case. Each dynamic record is matched to its generator by bus number and machine ID and keeps its parameters per unit on the machine base, with MBASE and the bus kV beside them; each contingency maps to the imported lines, transformers, generators and buses. Records and contingency elements the import cannot map are listed with their line in the import report.
