* Feat(pypsa-gui): New study harness profile `eh_ipp_hybrid@2`. Its explore stage runs the template's shipped cases with no proposal turn, and its solve budget is 5: the solve, two L2 rounds and two fork solves. `eh_ipp_hybrid@1` is unchanged. When more cases need a solve than the run has solves for, a pick card lists them with tick boxes. Cases that need no solve always run and read not evaluated. The approval card then lists all eight cases in file order, each change as old → new with its unit (a price reference shows its series' file hash and Library ref). It also shows the save of an unsaved project before any fork, and it binds the pick.
