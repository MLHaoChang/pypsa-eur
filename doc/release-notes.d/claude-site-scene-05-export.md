* Feat(pypsa-gui): "Export for Blender" on the Site canvas downloads a snapshot of the 3D site as a zip of a 3D model file (GLB, metres, Y-up) and a manifest (Site origin, axes, scene revision and hash, feature IDs, model bindings, source classes, content hashes). It needs no Blender, includes no photos, writes nothing to the project, and is available read-only too. Features that cannot be exported faithfully are listed by name in the manifest, never guessed.
