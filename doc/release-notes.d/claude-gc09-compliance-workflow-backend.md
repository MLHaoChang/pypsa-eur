* Feat(pypsa-gui): Grid-compliance workflow API (GC-09). `/api/grid-compliance` tracks the 25 TRGC deliverables of a grid connection: status with a guard that refuses submitting a study whose prerequisites are not judged, a data list per deliverable, a data freeze that stamps a model-set id and flags later input edits as stale, a TSO comment / revision log, and a per-deliverable report pack (DOCX skeleton, optional PDF, CSVs and a hashed manifest).
