* Feat(pypsa-gui): Grid-compliance workflow API. `/api/grid-compliance` tracks the 25 TRGC deliverables of a grid connection. A study cannot be submitted while its prerequisites are not judged or its data freeze is not fresh. Each deliverable has a data list, a data freeze that stamps a model-set id (campus input, asset library and network inputs) and flags later edits as stale, a TSO comment / revision log, and a report pack (DOCX skeleton, optional PDF, CSVs and a hashed manifest).
