* Feat(pypsa-gui): Site 3D can import a campus layout as a reviewable preview. A GeoJSON file in WGS84 or a PNG, JPEG or WebP drawing can be used: on a drawing you mark a scale bar, an anchor point and a rotation, then trace the building outlines. The drawing stays in the browser; only the scale, the placement and the outlines are sent. Missing scales, projected coordinate systems, remote references, holes, oversized images and DXF, IFC, PDF or SVG files are refused with a named reason before any geometry is built. A layout building's corners can be corrected by hand. Nothing is saved until Apply, and the import never replaces the rest of the site.
