* Feat(pypsa-gui): The assistant can write values from an uploaded PDF datasheet onto assets (data-to-model slice 2). Each value is cited by its page and the exact words that hold it; the server finds the quote on that page, reads the number from it (refusing ranges, tolerances and separators that read two ways), checks the unit against the field's schema and the currency against the quote and the project, and shows each value beside its page and quote on the edit card before anything is written. PDFs are parsed in a child process with a time and memory budget.
