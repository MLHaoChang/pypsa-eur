* Perf(pypsa-gui): The campus study's island checks run faster, with every result unchanged. The frequency simulation works out each unit's constants once per run instead of at every step (about 2x, the same numbers to the bit). The study's island hours and the cuts' failing events run over worker processes (`GRIDSPINE_WORKERS`; default one less than the CPUs available, at most 4; always one in the packaged desktop app), the tables in the same order at any count; `campus_workers.json` beside the run notes the count used. Called from gridspine directly, the checks run in one process unless a worker count is given. The every-hour E1 sweep skips building the units of an hour with nothing across the PCC. An abort now ends the run inside the island checks or the cuts, with its workers, rather than at the next stage, and the cuts show as their own step in Guided and Expert.
