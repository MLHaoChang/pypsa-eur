* Fix(pypsa-gui): A project's input fingerprint no longer depends on what else the API process has loaded. PyPSA adds the extra Link ports (`bus2`, `efficiency2`, ...) to every network once any network uses them, and these unused ports showed an unchanged study as out of date or forced a recompute. The fingerprint now hashes only extra ports a network sets. A study whose saved network carries unused extra-port columns shows out of date once after the update.
