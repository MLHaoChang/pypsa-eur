* Feat(pypsa-gui): The assistant creates and runs 1–4 sensitivity cases in one confirmation card that lists each case's name (derived from its changes when none is given), every asset's base → case value and the number of solves it queues. It asks to save an unsaved baseline first, asks for a new name on a clash, reports every case's status (a failed one with its cause) once the last job ends, and highlights the new cases in the Scenarios panel.
