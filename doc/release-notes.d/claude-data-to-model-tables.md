* Feat(pypsa-gui): The assistant maps an uploaded CSV/XLSX equipment table onto several assets of one class. Every changed value appears on one old → new edit card with its file, sheet and cell; units are converted only by the field's own display scale; cost columns state their currency and money year. Unmapped cells are listed with a reason and never written. Formulas are never evaluated. Each written field's provenance names its source cell, and one undo reverts the table (`preview_equipment_mapping`, `apply_equipment_mapping`).
