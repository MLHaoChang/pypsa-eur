* Feat(gridspine, pypsa-gui): Named ESS/UPS/converter control presets in the island sidecar. The four presets are `grid_following`, `grid_forming_support`, `fast_frequency_response` and `voltage_support`. Each sets the converter mode, droop, inertia and UPS behaviour. A project selects one with `POST /island/preset`, and both the island study and the gridspine campus studies read it. `offered_services` reports which grid services a project's converters offer. `get_island` now also returns the presets, the services and a `preset_leaves_no_grid_former` warning. Existing island configs load unchanged.
