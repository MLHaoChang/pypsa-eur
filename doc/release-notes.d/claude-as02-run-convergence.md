* Fix(pypsa-gui): The assistant no longer marks numbers from a partly converged AC power flow as checked. A run where some snapshots did not converge is refused for checked answers, with the count ("5 of 8 snapshots converged"). So is a run that does not record how many converged. The run can still be shown as unchecked data. A run that records every snapshot as converged is not yet proven sound: when PyPSA gives no convergence data, the app still counts every snapshot as converged, which is tracked separately.
