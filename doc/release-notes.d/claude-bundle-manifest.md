* Feat(pypsa-gui): A project bundle now carries a `manifest.json` with its format version, the app version, the project kind and the size and checksum of every file. An import refuses a damaged bundle or one from a newer app in plain words, with nothing left behind; an older bundle without a manifest still imports, with a warning. `POST /api/projects/import_bundle?dry_run=true` runs every import check and answers what the import would create (name, kind, files, what is stripped or ignored, a name clash) without writing anything.
