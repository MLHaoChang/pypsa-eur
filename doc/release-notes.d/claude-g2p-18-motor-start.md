* Feat(gridspine, pypsa-gui): Motor-start voltage-change screen at the point of connection (grid-to-process issue 18, 12a). A process unit gains `motor_kw`, `start_method` (`dol`, `soft` or `vfd`, with a default start current of 6, 3 or 1 × rated) and `i_start_pu`, which overrides that default. `gridspine/static/motor_start.py` estimates ΔU % = (S_start · sin φ_start − Q_gfm) / S_sc × 100, with S_sc = S_k''min / c_min on the PoC's minimum short-circuit case when the project's campus description states one, else the entered S_k'' / c_max with a note. The starting power factor per start method and the rated kVA per kW are ledgered demo values. Q_gfm is the reactive power of the grid-forming batteries in the island requirements; when it cannot be stated it is 0 (conservative) and the row says so. The grid-readiness scorecard gains one row per process unit, judged on the profile's existing `rvc_limit_pct`; a shipped demo limit is called a planning level, not an emission limit allocated to this installation. A unit without a motor rating or start method reads unknown, never pass, and a project with no process unit gets one unknown row, so the pilot evaluation's data-centre scorecard now has 19 rows not checked.
