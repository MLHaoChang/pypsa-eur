* Feat(pypsa-gui): The data-center templates take an opt-in AI-training load profile (`{"dc_load": {...}}` when creating the project). The load is IT MW × job/checkpoint utilisation × a temperature-dependent PUE, split by the critical share. The project stores a per-phase dynamic envelope (swing, max ΔP/Δt, checkpoint dip, oscillation band) for later grid-readiness checks. Every default is labelled assumed, with a source. Without the opt-in the templates are unchanged.
