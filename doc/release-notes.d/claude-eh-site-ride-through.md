* Feat(pypsa-gui): The generic site form has an opt-in "Ride through grid outages without a blackout" field, off by default. On, the site is studied under the seamless island scenario as well as the UPS-bridged one: the plan keeps enough battery online to hold the site the instant the grid is lost. The ledger says it is expected to cost more than the UPS-bridged plan and how to see the extra (the same site with ride-through off). With ride-through off, a site is built exactly as before. A site with no existing battery and no new batteries allowed cannot ride through, and the field says so. The assistant can set it as `ride_through` on `eh_site`.
