* Feat(pypsa-gui): Projects can have read-only viewers. A viewer can open a project and read its network, runs, reports and deliveries. Every change, undo, snapshot restore, queued solve and chat write is refused with one clear message, and the role is checked again when queued work runs, so a demoted or removed member's queued solve is not saved. A viewer can still comment on a report, withdraw their own comments and export a report file while an editor has the project open. This release adds the server-side enforcement; choosing a member's role in the app follows separately.
