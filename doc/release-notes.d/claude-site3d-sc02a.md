* Feat(pypsa-gui): Site 3D scenes can attach buildings and groups of buildings (complexes) to existing loads (one per carrier), process units and inventory stores, with explicit load shares that must total 100 %, and can place existing equipment, including solar panels on an eligible roof. Attachments follow the component through renames; a deleted or same-name recreated component is never re-attached by name, only by an explicit, confirmed re-attach. Placing equipment changes the scene only, never the model.
