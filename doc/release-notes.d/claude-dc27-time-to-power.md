* Feat(pypsa-gui): A checked "time to power" fact for data-centre projects (`time-to-power/1`, formula `dc-time-to-power/1`): calendar months from the stated project start to first power, a partial month rounded up. First power is the stated grid connection date, else the staged build's first model period with grid power while data-centre load is in service. The data-centre spec takes optional `project_start` and `connection_date`; the staged example states its financial close as the project start. A project without the inputs reads not available with its reason, never 0.
