* Fix(pypsa-gui): Snapshot create and restore, Save As, Save a Copy, scenario copies and project bundle export and import now take each report's write lock before copying a project's reports, so a copy no longer reads or replaces a report while a comment revision, template bind or report job is writing to it. A copy that cannot get the locks within a few seconds refuses with 409 `report_busy` and writes nothing. Bundle import refuses an archive whose `reports/` folder names anything other than a report.
