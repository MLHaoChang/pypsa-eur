* Fix(pypsa-gui): Snapshot create and restore, Save As, Save a Copy, scenario copies and project bundle export and import now take each report's write lock before copying a project's reports, so a copy can no longer mix a report's files from before and after a comment revision, template bind or report job. A copy that cannot get the locks within a few seconds refuses with 409 `report_busy` and writes nothing. Bundle import refuses an archive whose `reports/` folder names anything other than a report.
