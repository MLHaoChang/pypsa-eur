* Feat(pypsa-gui): Grid readiness: a project can enter its point-of-connection X/R (`poc_xr` in the project settings, `PATCH /api/projects/{name}/settings`; a finite number in (0, 100], null clears it). An entered X/R replaces the assumed X/R 4 in the rapid-voltage-change row, its after-battery value and the flicker row's GPU-envelope unit. It no longer marks the RVC row assumed and lifts the X/R-free bound guard, so a row that warned only because the X/R was assumed can now pass on the voltage form; the note names the PoC the X/R is applied to. With no X/R entered, the scorecard is unchanged. There is no UI field yet (API only).
