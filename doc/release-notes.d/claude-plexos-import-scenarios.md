* Feat(gridspine): PLEXOS import, slice 3a. The scenarios of the chosen PLEXOS Model now apply: a scenario's value replaces the base value, and a scenario can switch a data file (PLEXOS-World's adjusted wind and CSP files). Rows scaled by a Variable (× ÷ + -) take its static or file profile before conversion. Two scenarios setting the same value, a sampled or conditional variable, or a division by zero are listed in the import report with the reason; nothing is guessed. A PLEXOS-World 2015 Model needs its `*.adjusted.csv` wind and CSP files in the upload: without them its wind (and CSP) profiles are left out and listed in the report, never read from the unadjusted files.
