* Feat(pypsa-gui): Site 3D scenes have a read-only results route, `GET /api/projects/{name}/sites/{site_id}/scene/results`. At one exact native snapshot it returns the native port flows of each building's bound load, process unit, store or storage unit, with its signs and units (t/h on tonne buses, never MW; tonnes from MWh only through the bus's own `mwh_per_t`). It also returns each process group's boundary flows, with internal transfers excluded, and optional weighted window totals. A number that cannot be resolved is `null` with `available: false` and a reason, for example a stale, failed, cancelled or unsolved run, a run after an AC power flow, a missing factor or a partial share. A genuine zero stays available. Changing scene geometry keeps the run; changing an electrical input does not. Nothing is solved or interpolated.
