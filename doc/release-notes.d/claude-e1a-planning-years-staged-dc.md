* Feat(pypsa-gui): The staged data-center example can be created for any planning years. `POST /api/projects/from_template/eh_datacenter_staged` takes `{"planning": {"start_year", "end_year", "dates"?}}`. The investment periods are the start year and the dates; without dates, the example's own spacing is shifted to the start year. Each period's years run to the next period, the last to the end year, and the solve's auto-discount weights them. The investment case runs from the start year to the end year. An IT load or energization the example has no figure for in an entered year is the example's same-stage value, marked a placeholder: the flow warns about it, the peak check and grid-readiness scorecard read that period as unknown, and the investment case flags it. A refused entry is a typed 422 `planning_invalid`. Without `planning`, the template is unchanged (E1a).
