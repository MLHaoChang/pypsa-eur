* Feat(pypsa-gui): The assistant's "why this number" tool now explains a calculation metric that a checked evidence record answered. It takes `evidence_id` and `metric` and shows each raw input, the window and the value the metric was computed from. Each is compared with the open network now, so an edited input reads stale. A retained run, or a network busy with a solve or an edit, reads uncompared and is never shown as fresh. The run the metric was computed in is also not compared yet, so a metric's answer never reads fresh. The tool still changes nothing. The route is `GET /api/chat/evidence/{evidence_id}/why/{metric}`.
