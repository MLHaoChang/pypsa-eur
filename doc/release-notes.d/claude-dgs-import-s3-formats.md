* Feat(gridspine): The PowerFactory import reads DGS 7.x files (PowerFactory 2021 and later: FID keys, create rows only, matrix attributes listed as not imported, a decimal comma read as a point) and the DGS Excel form (one sheet per class, typed headers in row 1). The Excel layout follows third-party documentation and has not been tested against a real PowerFactory export. A `.xlsx` upload goes to the PowerFactory or the Excel input workbook importer by its content; a workbook both or neither recognise is refused.
