* Feat(gridspine): The PowerFactory import reads DGS 7.x files (PowerFactory 2021 and later: FID keys, create rows only, matrix attributes listed as not imported, a decimal comma read as a point) and the DGS Excel form (one sheet per class, typed headers in row 1). The Excel layout follows third-party documentation and has not been tested against a real PowerFactory export. The import registry's new `for_file` picks the importer for a `.xlsx` by its content: a workbook with a PowerFactory `General` sheet goes to the PowerFactory import, and any other to the Excel input workbook import; the upload flow calls it once the import pipeline lands.
