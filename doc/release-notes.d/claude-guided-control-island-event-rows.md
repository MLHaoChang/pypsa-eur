* Fix(pypsa-gui): Seamless islanding now also keeps headroom for the island's own events, the ones the frequency check judges: the largest load step, the trip of any one unit (a charging battery's trip included) and the loss of the PV. Before, it kept headroom for the islanding step only (new I2b rows `Island-e2-up`, `Island-n1-up/-down-<unit>`, `Island-e5-up`). This can raise battery sizes on any seamless site, including the generic site with `ride_through` on. On the staged microgrid the GFM settings recommender now reaches a recommendation at the Guided default ranking (k=3), and the demo's pre-tax NPV moves from +43.9 M to +43.2 M EUR. The solver's infeasibility hints now name the island rows.
