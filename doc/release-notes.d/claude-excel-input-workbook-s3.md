* Feat(pypsa-gui): The Excel input workbook in the app. The Export chooser offers "Input workbook (Excel)" (the project as last saved, with "Save first" while edits are unsaved) and "Blank input workbook (Excel)". A filled workbook is imported as a new project from Guided's Start card ("From a filled workbook") or Expert's New project › From file: a dialog shows what it would create (rows per sheet, what was left out or assumed, warnings, costs worked out again), takes a project name, creates the project and opens it. An input workbook dropped on the Import dialog goes to the same preview, and the open network is not changed.
