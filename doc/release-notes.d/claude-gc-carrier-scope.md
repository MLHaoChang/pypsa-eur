* Fix(pypsa-gui): An operational limit or a technology capacity-expansion limit on a carrier (Solver Settings' global constraints, the fuel limits per period, or one the assistant creates) now binds in the solve. PyPSA reads the carrier of these two constraint types from `carrier_attribute`, but the app stored it in `carrier`, so the limit was silently ignored (a 40 MWh gas cap let gas run 200 MWh). The carrier is now written to both, and a project saved before this fix is repaired in memory when it loads; its file is updated on the next save.
