* Feat(pypsa-gui): A checked answer to "what is the capacity of <class> <name>?" first asks which capacity is meant (configured input, optimized result or available) through the existing choice card, and publishes no number until the meaning is chosen. The configured input is a new `configured_capacity` metric in the class's own unit; available capacity stays explicitly unavailable (`available_capacity_not_checked`) and is never derived from availability limits.
