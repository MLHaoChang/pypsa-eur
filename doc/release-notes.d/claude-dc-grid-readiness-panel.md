* Feat(pypsa-gui): The grid-readiness scorecard in the GUI and the report (DC grid readiness 02, part B). It is read only and advisory, with each verdict shown as a word and an icon, and "assumed" badges on assumed limits. Rows are grouped by project-flow section, and the grid code's dynamic requirements collapse into one "Needs a dynamic (EMT) study" group. In Expert it is a "Grid readiness" group under RUN › Issues, where "Go to field" opens the input's component. In Guided it is a collapsed line on the Site card ("Grid readiness: 3 things to look at, 7 not yet known"), with Ask on each row and, where the input is a field, the place Expert edits it. Reports of hub projects get a "Grid readiness (screening)" chapter, with its table and disclosures (advisory; before UPS/BESS smoothing; EMT needed; the assumed limits by name).
