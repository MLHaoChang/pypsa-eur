* Feat(gridspine): the PSS/E `.dyr` writer adds the rest of the WECC second-generation set: REECC1 (battery electrical control, v35), REPCA1 (plant controller on the plant's PoC branch, with BUS1, BUS2 and CKT taken from the RAW) and the type 3 wind records (WTDTA1, WTARA1, WTPTA1, WTTQA1). It also takes a new `version=33|35` argument, pins each model's ICON/CON counts with its public sources, and refuses REGC_B and REEC_D (user models only), a missing PoC branch and contradictory flag sets. The REGCA1/REECA1 and synchronous-machine output is unchanged, except that a CON filling all ten columns (such as `-999.00000`) now keeps a blank before it instead of running into the previous value. Unit-template overlays now refuse non-finite values.
