* Feat(pypsa-gui): Typed cost units in the defaults pack. Every cost row of the new EU version 2026-10-22 and the regional versions 2026-10-22+{ca_federal,uk,us_federal} states `capacity_basis` (what its capacity measures), `includes_grid_connection` (true, false or "unknown") and `money_year`; the loader refuses a row without them. `price_from_pack` now scales a price by the ratio from the component's nominal to the row's basis, one table for component x basis: a fuel-cell Link (price per kW out) still scales by its efficiency, an electrolysis Link (price per kW in) no longer does (it came out about 38 % too cheap), and a Haber-Bosch Link scales by its NH3 bus's efficiency; an inconvertible pair is refused. The stamp and the asset provenance carry currency, money year and grid-connection fact; the battery branch returns the pack's currency instead of an EUR key on regional packs. A new `commercial.grid_connection_double_count` warning flags a pack row that includes the connection on a project that also charges a capacity fee. Versions up to 2026-10-20 and 2026-10-21+* stay as shipped, load for provenance, and refuse pricing (`LegacyPackVersion`); the Energy Hub templates, the ammonia hub, the IPP template and the redundancy scenarios now price from 2026-10-22 with the same numbers.
