* Feat(pypsa-gui): Asset-sizing loop runner (AS-06, part 2). `services/adequacy/sizing_loop_runner.py` runs the loop on a private copy of the network through the AS LP chain. The forward pass runs on the solved capacities and covers the transformer library round-up, the exact PQ circle, ESCR, the smoothing floors, analytic Pst at S_k''/c, an optional harmonics filter cost, and optional campus-model adapters, which are named when they don't run. Inner rounds use a tsam-reduced year, and a full-year final solve gives the verdict. Each round records its run time. A converged run writes the AS-07 control-settings sheet next to the dyr file. The prototype's weak-flat intent D case converges in 2 rounds.
