* Feat(pypsa-gui): A chat-started solve now keeps its Summary results (the `statistics` and `cost_breakdown` reads) with the run, beside its load flow. `get_results(result_kind, run_id)` answers an older run from what it kept, never from the current results, and a run without them refuses with its run ID. Both families share one retained-results adapter (`services/retained_results.py`); a section too large to keep is dropped with a `<section>_not_captured` warning instead of losing the run's manifest.
