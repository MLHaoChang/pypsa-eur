* Feat(pypsa-gui): PSS/E, PowerFactory DGS and PLEXOS model files can be imported into a new project through `/api/model-import`. The routes list the formats from the importer registry, show a preview that writes nothing (counts, then every item not carried and every assumed value, in plain names), and then create the project, all or nothing. The importer runs in a separate process with a time and memory limit. The screens follow in a later change.
