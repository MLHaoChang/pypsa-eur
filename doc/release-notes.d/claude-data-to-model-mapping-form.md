* Feat(pypsa-gui): An "Import rows from a table…" form in the Lines, Transformers, Loads, Generators, Storage, Stores and Links asset tables maps an uploaded CSV/XLSX onto that class's assets. You pick the upload, the name column, and a field and unit for each column from the field schema. The preview is the same old → new edit card the assistant shows, with every value's source cell. Apply writes exactly that card and shows its receipt, then offers to open the section the assets belong to. The preview is a read and leaves undo and results untouched. The apply now also checks that each written value equals the card's new value, and the assistant's apply rechecks the card the user approved.
