* Feat(pypsa-gui): The Companion's in-page chat gets a "Start voice" toggle beside Send for continuous voice when the server's speech session is enabled (`PYPSA_GUI_LIVE_SPEECH`). Without a media link the toggle stays disabled and the reason is shown. The microphone track stops on Stop voice, an error, closing the chat, a hidden tab, leaving the page, a project switch, a conversation rebind, a revoked or unplugged microphone and the session time limit. Each stop leaves one plain line ("Voice stopped: this tab was hidden."), and typing continues in the same conversation. No media SDK is added, and the shipped app is unchanged.
