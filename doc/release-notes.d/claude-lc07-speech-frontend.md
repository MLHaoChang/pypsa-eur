* Feat(pypsa-gui): The Companion's "Start voice" button starts continuous voice in the in-page chat when the server's speech session is enabled (`PYPSA_GUI_LIVE_SPEECH`) and a media link is configured. With the flag on but no media link, it stays disabled with that reason. The microphone track stops on Stop voice, an error, closing the chat, a hidden tab, leaving the page, a project switch, a conversation rebind, a revoked or unplugged microphone and the session time limit. Each stop leaves a one-line reason ("Voice stopped: this tab was hidden."), and typing continues in the same conversation. No media SDK is added.
