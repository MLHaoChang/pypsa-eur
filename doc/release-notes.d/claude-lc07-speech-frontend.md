* Feat(pypsa-gui): The Companion "Chat here" composer can start continuous speech ("Speak" beside Send) when the server's speech session is enabled (`PYPSA_GUI_LIVE_SPEECH`) and a media link is configured. The microphone track stops on Stop, an error, closing the chat, a hidden tab, leaving the page, a project switch, a conversation rebind, a revoked or unplugged microphone and the session time limit. Each stop leaves a caption naming the reason, and typing continues in the same conversation. No media SDK is added, and the control stays hidden in the shipped app.
