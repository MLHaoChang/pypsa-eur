* Feat(pypsa-gui): The losses summary (`/results/losses`) gains an additive `validity` record. It is built from the raw values before they are zero-filled and aligned to the network's snapshots. Per component (Line, Transformer, Load) it counts entities that are complete, incomplete, absent or misaligned, and values that are finite, zero, missing or infinite, so a missing loss value no longer reads as 0 MW. The existing fields are unchanged (assistant-assurance 10, A1.7).
