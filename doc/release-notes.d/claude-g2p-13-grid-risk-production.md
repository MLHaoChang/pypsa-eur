* Feat(pypsa-gui): "Grid risk to production" turns each grid risk of a process site (voltage-dip ride-through, island on a grid outage, N-1 of the site transformer, connection curtailment) into lost tonnes, then EUR, per year, with each line's source file. A missing input reads "Missing", never 0, EUR reads "Unavailable" without a lost-production value, and the total is labelled an upper bound because the lines may overlap. It is a Reliability tab in Results (shown only when the network has process units), the `get_grid_risk_production` chat tool, and a report chapter.
