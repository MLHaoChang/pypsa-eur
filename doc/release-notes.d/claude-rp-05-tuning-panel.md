* Feat(pypsa-gui): In Expert mode, Time Series › Renewables gets a "Tune…" link on each wind and solar generator with a location. It opens a dialog listing that technology's settings (hub height, derate, tilt, azimuth, losses and so on) with their units, preset values and bounds; fields only the ERA5 source uses are disabled with the reason while the weather is Synthetic. Generate queues a profile without applying it, and a before/after comparison against the generator's current profile (week overlay, duration curves, full-load hours, capacity factor, peak and P10/P50/P90 with their differences, all computed by the server) comes first; Apply writes it as one undo step. The weather bar says which dates a sampled model takes from the weather year, and the assistant gains a read tool for the tuning settings (`get_profile_tuning_schema`).
