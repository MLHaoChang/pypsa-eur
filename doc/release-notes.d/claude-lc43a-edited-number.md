* Fix(pypsa-gui): An edited Word copy of a report can no longer change an admitted number unflagged. An edited table that brings in a new number keeps the admitted table in the next version, with a withheld placeholder and the new number listed under "Numbers to check"; edited prose is re-audited against the facts the previous version verified, so a changed number is listed there as unverified (or withheld, in a section whose table was withheld). Edited tables are matched to the report's own tables by content, so a table inserted above another cannot slip an edit past the check.
