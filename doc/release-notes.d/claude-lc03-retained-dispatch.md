* Feat(pypsa-gui): A chat-started solve now keeps a bounded digest of its Dispatch results with the run (`services/results/dispatch_digest.py`): per carrier and per unit, weighted energy, peak and its snapshot, weighted mean and running hours, with storage discharge and charge kept apart. `get_results(result_kind='generators' | 'storage_dispatch', run_id=…)` answers this digest for the current and for an older run alike, and refuses a source or paging argument rather than return a full series it did not keep. Multi-period networks are not digested.
