* Feat(pypsa-gui): Add the generic site template `eh_site`, a parametrized Energy Hub for anything that is not a data center. Pick a site type (industrial, commercial, hospital, campus, other) whose preset fills every parameter, and override any of them: the peak load per growth stage and its weekly shape, the grid connection and its energization, the existing gensets, PV, battery and UPS, and the genset, battery and PV candidates per stage. `POST /api/projects/from_template/eh_site` takes these in its body. It refuses a stage whose peak is above the connection energized in it before any project is created, naming the field, the stage and the shortfall. It binds the site's commercial and finance inputs, so a solved plan has an investment case against a grid-only site that runs under its own connection. The assistant's `create_project_from_template` tool takes the same `params`.
