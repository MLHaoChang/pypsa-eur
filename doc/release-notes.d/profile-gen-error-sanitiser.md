* Fix(pypsa-gui): Profile routes and the assistant's profile tools no longer echo an unexpected exception's text. A typed refusal still says its own sentence unchanged; any other error says only its type ("unexpected error (TypeName); see the server log"), and its text and traceback go to the server log with the route and job id. A failed ERA5 download keeps the library's message, which can carry the request URL, in the log as well.
