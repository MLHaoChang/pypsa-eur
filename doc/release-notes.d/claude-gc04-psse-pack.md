* Feat(gridspine): the campus bundle now also writes a PSS/E v35 study pack in its own `psse_v35/` folder. The pack holds RAW, `.seq`, `.dyr`, `.con`/`.sub`/`.mon`, psspy scripts, a README and a manifest. A grid-following converter with no supplied dynamic parameters gets the public generic WECC set: REGCA1 + REECA1, REECC1 for a battery, and REPCA1 on the aggregated plant (a battery plant may charge and responds to low frequency). Every value in that set is tagged `assumed` and listed, and the pack is marked "not for submission until replaced with OEM data". The manifest lists what the `.seq` leaves out or assumes, and cites the GC-01 model set when one is given. The bundle's own `.raw`, `.dyr`, README and GFM table are byte-identical; its `manifest.json` gains a `psse_pack` entry. A synchronous `.dyr` CON that fills all ten columns now keeps a blank before it, as the converter records already did.
