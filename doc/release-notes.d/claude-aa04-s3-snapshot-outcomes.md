* Feat(pypsa-gui): The assistant's undo, network import and network export lines now say whether the change landed, from an independent read-back. An undo reads "done" only when the network, user series and template data match the change it undid. An import reads "done" when the network holds exactly the file's rows and values, and "partly done" with a count when rows are missing or extra. An export reads "done" when the one file the call wrote reads back as the live network; csv bundles compare floats to 1e-12 relative, since csv stores numbers as text. Excel and MATPOWER files read "outcome unknown: this file format cannot be checked yet".
