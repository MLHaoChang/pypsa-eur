* Feat(pypsa-gui): A "Market pack" card under the market prices in the tariff editor (Guided and Expert). Pick a bidding-zone pack (NO-1 to NO-5) and see every value it would change, old → new, beside the values kept as yours. Then apply it and read the receipt. The card also names each reserve product that has no price, with a place to pick its Library series. It carries the "Confirm no backup obligation" storage list.
