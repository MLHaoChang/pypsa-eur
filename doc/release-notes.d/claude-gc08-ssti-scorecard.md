* Feat(pypsa-gui): The grid-readiness scorecard shows the campus run's SSTI and sub-synchronous screens (grid-compliance GC-08, TRGC 19, 20) as three screening rows: the unit interaction factor against the threshold the run used, the series resonance's least torsional margin against its clearance, and SSCI, which is never evaluated here. A flag warns. A screen that could not decide, a failed or missing run, or a threshold changed since the run reads unknown with the reason. On an off-grid project the two rows scanned from the PCC are left out, and with the tie open the UIF row reads unknown, because the screen counts the grid's infeed. The binding answer is the EMT study.
