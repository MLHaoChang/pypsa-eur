* Feat(pypsa-gui): The intent-A backup autonomy for the design-intent comparison is now stored with the project (`settings.backup_autonomy_h` in `metadata.json`, `PATCH /api/projects/{name}/settings`; default 4 h, finite, above 0 and at most 720 h, 422 otherwise). A bad stored value reads back as the default, and a misspelled settings key is now a 422 instead of a silent no-op.

* Fix(pypsa-gui): Save-As and Save-a-Copy now carry the project's settings (including "Derive lengths from geometry") to the new name; before, the copy started from the defaults, and a forced Save-As over another project kept that project's settings. A settings edit also no longer races a concurrent save of the same project.
