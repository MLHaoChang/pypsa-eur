* Feat(pypsa-gui): When a run you started ends, a notice says so: "Campus study finished: Project X · 6 min" with **Open results**, "… failed: Project X" with **See why**, or "Run stopped when the app restarted: Project X" with **Run again**. Finished notices go by themselves; failed and interrupted ones stay until closed or the project runs again. Only one open tab shows each notice, at most three show at once, and runs that ended while the app was closed get one "N runs finished while you were away" summary. "Notify me when it finishes" on the running line, or **Browser notifications** under Preferences, also tells you through the browser while the tab is hidden; the browser notification names only the run, how it ended and the project.
