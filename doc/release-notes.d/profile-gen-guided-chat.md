* Feat(pypsa-gui): Guide renewable profile generation in chat. A new renewable-profile workflow walks scope (existing generators by name — bus coordinates seed the sites — or explicit coordinates), technology, turbine/panel presets, weather source (synthetic offline vs ERA5 with CDS credential coaching), and resolution (hourly, daily or weekly means aggregated at generation and upsampled back onto the network's hourly snapshots at apply; weekly applies to its own calendar year only), then previews, queues and applies with an undoable write. The preview/generate chat tools and Profile Studio expose the same resolution choice, and both chat tools accept generator names directly so a profile request needs no coordinates.
