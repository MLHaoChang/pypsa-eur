* Feat(pypsa-gui): Grid-readiness scorecard (DC grid readiness 02). One generic, advisory check for any project, `GET /api/campus-electrical/{name}/grid-readiness` and the copilot tool `grid_readiness`. It rates the project pass, warn, fail or unknown on the SCR, each period's peak against the energized import after losses plus firm gensets, the AI-training envelope's ramp rate, oscillation and rapid voltage change (before UPS/BESS smoothing), reactive range, frequency support, the grid-code profile's dynamic requirements (always unknown: EMT needed), grid former, island ride-through and LOLE. A missing input reads unknown, never pass. The EH templates mark their connection ramp, oscillation, loss-factor, fault-level and LOLE assumptions as ledger rows, and the scorecard's `assumed` flag comes from those rows. DC 01's create-time peak check and the scorecard share one function, which now counts the PoC Link's losses.
