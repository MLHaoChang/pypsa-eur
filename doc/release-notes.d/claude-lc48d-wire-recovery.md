* Feat(pypsa-gui): The assistant recovers from three interrupted states. A stored chat history with a tool call left without its result is sent with a synthetic `interrupted_tool_call` error result instead of failing every later turn (the stored history is unchanged). Approving a card shown before a server restart answers 410 `confirmation_lost_on_restart` ("ask again") and runs nothing. Starting a workflow while one is active, or another task while one runs, is refused with 409 `switch_in_progress` naming the active one.
