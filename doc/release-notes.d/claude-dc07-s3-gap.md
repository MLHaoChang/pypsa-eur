* Feat(pypsa-gui): Plan-vs-operation gap (DC 07, slice S3). An operational run now also solves the full horizon once on the same sizes, the same initial charge and with cyclic storage off. This is the "full-horizon dispatch on the same sizes". `GET /api/results/operational_gap` compares the two on opex, unserved energy, curtailed energy, storage discharge and the storage left at the end. Each metric is defined in the response, the windows are counted (failed ones included), and the response says which LP-only terms are excluded. A missing, stale or not-established comparison reads None, with a flag that says why.
