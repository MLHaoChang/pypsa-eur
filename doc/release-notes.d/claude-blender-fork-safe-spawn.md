* Fix(pypsa-gui): The Blender scene worker no longer runs Python between fork and exec when it starts the container CLI, which could hang the solve queue for good in the multithreaded API process. The CLI still gets no core dump (set by a fresh interpreter that then execs it), and a CLI that does not start within `Caps.spawn_s` (30 s) or is cancelled while starting now fails the job typed instead of blocking the queue.
