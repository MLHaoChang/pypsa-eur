* Feat(pypsa-gui): The in-app assistant can review the user's recent chats and runs for lessons (assistant memory slice 04a, the dream job). `POST /api/memory/dream` queues one job per user. The worker runs one analyzer call per past chat or run, then one organizer call, on the active provider profile, and writes `proposed` lessons only. The user confirms each lesson on the Memory page's Proposals tab, and a confirmed lesson links to the chats and runs it came from. Each job is capped by `PYPSA_GUI_DREAM_JOB_TOKENS` (200k by default) and by the daily token cap. At the cap it stops with `dream_budget_exhausted` and keeps what it proposed. A lease-guarded `memory_dream_jobs` table (migration 0014) makes the job resume after a restart without duplicate proposals.
