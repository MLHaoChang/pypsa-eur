* Feat(pypsa-gui): Campus island I7 chat tools. The assistant can read a hub project's frequency cuts with `campus_island_cuts`: the proposed cuts with their primal estimates and reasons, the applied cuts, the trials and the apply job. It can start the apply loop with `campus_apply_island_cuts`, which re-solves and saves the hub, refreshes the campus file's sizes and reruns the campus study, up to three trials. The apply tool checks the named project's edit lock and goes through the confirmation card in Expert and Guided mode.
