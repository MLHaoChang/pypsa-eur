* Feat(pypsa-gui): Asset-sizing loop engine (AS-06, part 1). Adds a pure controller (`services/adequacy/sizing_loop.py`) that solves, runs the forward checks and adds cuts, by the revised stopping rule. Cuts are never removed. Library assets round up and freeze after round 2. The loop stops at 5 rounds. A tolerance stop with a failing check is "not converged", a check with no lever is "unresolved", and harmonics price a filter instead of cutting. Adds the cuts as LP rows (`services/solver/sizing_cuts.py`): an import-flow cap, a GFM MVA floor for ESCR, and a Pst voltage row on P_sm and Q_dyn. Also adds an optional PQ margin on the AS-05 pq row. The new tags enter the input fingerprint only when set.
