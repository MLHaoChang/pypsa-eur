* Feat(pypsa-gui): Every field tooltip on an asset's Properties panel now comes from the asset schema, the text the Expert card and the add-asset form show, so the panel no longer keeps a second, older copy. The Bus tooltips and a line's per-km impedance tooltips are unchanged. The in-app assistant's `create_component` tool now lists, for each asset class, the attributes it takes, in stored units (per MW, fractions), with its investment parts. It also names the derived columns, such as `capital_cost`, so the assistant prices an asset by its overnight cost and lifetime instead of typing an annuity.
