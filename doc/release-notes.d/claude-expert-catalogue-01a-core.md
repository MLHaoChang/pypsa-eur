* Feat(pypsa-gui): Parameter catalogue core. ``GET /api/catalogue`` serves every asset type and every asset parameter with a plain name, one-line help, group, depth, the functions that read it, its default and its source, plus a first-draft guide entry for each (``GET /api/catalogue/guide/{id}``). It is cached by content hash and is the same for every project. The asset cards are unchanged in this release.
