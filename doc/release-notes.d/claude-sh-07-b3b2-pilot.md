* Feature(pypsa-gui): New Energy Hub site study runs use version 2 of the run profile (`eh_site@2`). The run asks for your reliability goal (LOLE, h/yr) and stores it on the new project before the run starts; without a goal, the run is not granted (`goal_missing`). The reliability check runs the ENS-cap coupling loop. Version 1 of the profile is unchanged, so a run granted before this change keeps `eh_site@1`. The no-shed check now reads multi-period solves: each investment period is weighted by its own generator weightings, and the check names the worst period. Approving a study run from chat data step by step now creates its project too, from the inputs the card showed; nothing runs unattended, and every later change and run asks you first.
