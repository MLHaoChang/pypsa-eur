* Feat(pypsa-gui): A shipped Library cost reference can be applied to one asset, from the assistant (`apply_library_reference`) or over `/api/network/library_reference/{preview,apply}`, always through the old→new edit card with the reference and the default it replaces side by side. It writes overnight cost, lifetime, fixed O&M and (for an electrolyser Link) efficiency on that asset only, records the reference, money year and approval in the asset provenance, and never scales an input-priced electrolyser cost by efficiency. AC-priced PV on an undeclared basis, a grid connection counted twice and a different money year each need an explicit confirmation; a non-EUR pack is refused.
