* Feat(pypsa-gui): One table now says what a project is and which operations carry each part. Bundles, Save-As and snapshots now keep the template marker, a template's sensitivity cases, the importers' records and a planning study's `gridspine/` folder; snapshots leave out its `run/`. A bundle carries the project kind. A bundle import is unpacked and checked in a private staging folder before the project exists: unsafe paths, links, names that clash on Windows or macOS, an oversized archive and an unknown kind are refused in plain words with nothing left behind; unknown members are reported and never written; settings that named folders on the exporting machine are cleared and named in plain words; priced rows are re-derived from their parts; and a failure after the project is created removes it, its open copy and the session's switch to it again.
