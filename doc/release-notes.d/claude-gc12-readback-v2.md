* Feat(gridspine): The pack read-back accepts battery contract version 2 and judges "stays connected" from the result's `connected` channel (PoC breaker status). The first 0 after the event is the trip and fails the case at that time. Blank status samples with no 0 read unknown ("status poll failed at t=…"). The case passes only when every sample from the event on reads 1. A version 1 pack has no such channel, so its "stays connected" row reads unknown ("no connected channel (contract v1)") on every case kind and no case passes. A `connected` channel in the wrong unit, or with a value other than 0, 1 or blank, leaves only that case unknown, naming the sample.
