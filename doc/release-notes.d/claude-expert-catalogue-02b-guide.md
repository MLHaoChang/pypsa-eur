* Feat(pypsa-gui): A Parameter guide explains each parameter from the catalogue: what it means, which runs need or use it, its default, related parameters, an example and its model-file name, with search and browsing by asset type, group and function. Shift+Enter on a parameter in the command palette (Ctrl K / ⌘K) opens it there, and parameters with no field (settings, constraints) now show in the palette and open in the guide. Assistant links to a parameter open it too. In Guided it opens inside the field drawer with "Back to" the field, in Expert over the Properties panel with "Back to" the asset; unsaved input is kept, Esc closes the guide first, and it never covers the assistant.
