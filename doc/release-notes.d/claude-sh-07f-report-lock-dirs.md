* Fix(pypsa-gui): Deleting or renaming a project, deleting or pruning a snapshot, a study option fork and the legacy import and claim no longer run while one of the project's reports is being written. They wait briefly, then answer 409 `report_busy`. A delete or rename also refuses while a report is being generated for the project, and a report writer can no longer re-create a deleted project's folder. A fork no longer copies the base project's report lock files.
