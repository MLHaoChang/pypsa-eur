* Chore(pypsa-gui): Pull requests that add assistant tools no longer regenerate or hand-merge shared JSON, so they merge in either order. The capability inventory, route-parity and control-matrix checks build in memory instead of comparing committed files. New error kinds and route-parity declarations go in per-PR fragment files (`pypsa-gui/tool-error-kinds.d/`, `smoke/assistant_route_parity_declarations.d/`). A declaration whose route a tool now serves passes as stale until a sweep command prunes it. The pre-merge gate also runs the frontend tests that read the tool list.
