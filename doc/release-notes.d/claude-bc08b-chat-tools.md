* Feat(pypsa-gui): Business case chat tools (business case 08b). The assistant can run, read and abort the business case (`run_business_case`, `get_business_case`, `abort_business_case`) and edit its lines (`set_business_case_lines`). An edit always shows a card, in Guided and Expert. The card lists each line added, changed (old → new) or removed, and each price's source. A new or changed price must cite the user's own message, an upload cell or a PDF page, checked by the run intake's reader; otherwise it is refused (`price_not_from_user`). The template preset stays in the panel. A stale business case reads stale with what changed, and an unknown figure reads "not established".
