* Feat(pypsa-gui): A project now keeps a copy of each Library price series, tariff, contract and connection agreement it pins, in its own `library/` folder, so a bundle opens and resolves its pins in another organization or after the Library entry was deleted. A copy is used only when it matches its pin; a changed copy is reported and never read. Opening a project says when the Library has a newer version of a pinned item, and the project keeps its pinned version until you re-pin it. Existing projects get their copies on their next save. An import refuses a bundle whose copy does not match its pin.
