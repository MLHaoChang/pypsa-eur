* Feat(gridspine, pypsa-gui): Harmonic-distortion screen at the point of connection for large drives and thyristor heaters (grid-to-process issue 17, harmonics part). `gridspine/static/harmonics.py` sums each unit's harmonic currents with the IEC 61000-3-6 general summation law (or arithmetically, one switch) and turns them into the voltage distortion per order and as THD against the grid code's limits. A process unit gains `rated_mva`, `harmonic_source` (drive topology or heater control, or `linear`), an optional vendor `harmonic_spectrum` and `spectrum_post_filter`; with no spectrum, the topology's demo default is used and the row says so. A unit with an input missing is reported as "no input", never skipped. The campus study writes `campus_harmonics.csv`, and the grid-readiness scorecard gains a harmonic-distortion row. Flicker, filters and IEEE 519 are not part of this change.
