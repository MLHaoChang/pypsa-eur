* Feat(pypsa-gui): Checked assistant answers now account for MIP solves. Whether a run is an LP, a MIP (committable units or extendable modular assets) or a stochastic run is read from the network. Every checked answer on a MIP names the relative optimality gap the solver was given, or says it was not recorded. A cost difference to a retained run that lies inside the two solves' combined gap is reported as unavailable, not with a sign. Bus prices on a MIP are never certified: HiGHS returns no duals there, and PyPSA writes 0 EUR/MWh. A run planned with linearised unit commitment counts as an LP. The checked bus-price chart is not drawn on a MIP. A retained run sealed before this change has no solve record, so a cost difference to it reads "gap not recorded", even between two LPs (assistant-assurance 10, S2).
