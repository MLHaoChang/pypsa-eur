* Feat(pypsa-gui): A project now records which weather cutout each applied renewable profile came from: the cutout's own area, its weather year and a fingerprint (sha256) of its file. The record travels with the project's bundle, Save-As, fork and snapshot, and the weather settings answer lists it. Re-applying a profile replaces its record, and applying a synthetic profile removes it. The cutout itself stays in the shared weather cache.
