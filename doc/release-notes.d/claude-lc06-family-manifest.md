* Feat(pypsa-gui): Added `smoke/family_manifest.py`, the LC-06 execution manifest. It assigns every assistant tool to one of the 14 capability families and lists each LC-D01–24 engine/control variant as covered (public-seam test plus hand oracle), pending or unavailable. A guard test refuses test ids that do not collect, stale tools, tools listed in two families and unavailable rows without a pointer; new tools are reported as unmapped and stay in the denominator.
