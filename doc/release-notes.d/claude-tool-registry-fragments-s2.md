* Chore(pypsa-gui): Hardened the per-tool chat registry fragments. A tool family moved into a fragment pair now keeps its old place in `TOOL_ROUTES` and the chat dispatchers as well as in the tool list, and `smoke/tool_registry_digest.py` hashes both in that order. Each fragment tool must unwrap to its own dispatcher through exactly one wrapper per gate it is in. Every dispatcher fragment is checked for circular imports. `smoke/check_bundle.py` refuses a build missing any fragment module.
