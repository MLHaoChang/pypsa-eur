* Feat(pypsa-gui): The chat assistant can use tools from MCP servers a super-admin lists in `mcp-servers.json` under the app data directory (none by default). Their tools are offered to every provider as `mcp__<server>__<tool>`, are fixed for the chat session, and need the confirmation card in Expert and Guided mode unless the server marks them read-only; their results are fenced like any tool result.
