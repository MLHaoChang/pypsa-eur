* Feat(gridspine): the PSS/E hand-off adds a `.con` writer with its `.sub` and `.mon` files (`contingencies.write_con`, `write_sub`, `write_mon`). Its output reads back through the GC-03 contingency importer. Compound contingencies are returned as not written, and an element that is not on the network is refused before any file is written. A new `psspy_scripts` module writes one psspy script per test-battery case and checks each script with `ast`: the files it may open, its imports, and the channel names. Every channel is written to CSV under its contract name and in contract units. The psspy call signatures are marked pending verification on first PSS/E run.
