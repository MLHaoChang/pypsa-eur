* Feat(gridspine): The campus study's PSS/E handoff (`psse_campus`) takes the aggregated plant and the GC-01 model set with its variant and gives them to every island hour's bundle, so its packs can hold REPCA1, the psspy test scripts and the model-set citation. A model set that is not the run's own campus (its model hash differs) is refused before anything is written. The bundles are now written aside and replace `psse/` whole, so a refusal keeps the previous tree and a new run never mixes with an older one. Without a plant or model set the files are byte-identical to before. No app caller passes a plant yet (GC-04e).
