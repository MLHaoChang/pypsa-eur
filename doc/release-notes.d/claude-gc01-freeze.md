* Feat(gridspine): `freeze` (`gridspine/ingest/aggregate.py`) builds and checks the detailed and aggregated plant models and returns the versioned model set (TRGC 01/02); an error in either variant is raised, never turned into a missing one. `aggregate_hour` maps the detailed hourly dispatch onto the aggregated equivalents and refuses, by name, a unit it cannot map, an unknown, missing or blank column value, and whatever the hourly table check refuses (non-finite power, a status other than 0 or 1, power on an off unit, duplicate rows).
