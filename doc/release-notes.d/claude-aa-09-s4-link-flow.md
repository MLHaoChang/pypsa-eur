* Feat(pypsa-gui): The assistant can give a checked flow for one Link (`link-flow/1`, opt-in): the net energy into the link at bus0 and out at bus1, the conversion loss, the peak flow, and the peak loading of the optimised capacity, for the whole run or an exact window. It follows PyPSA's sign convention and reads the link's time-varying efficiency where it has one. Every figure is withheld, with a named reason, for a link with a third port or a flow that does not match its efficiency. Only the loss is withheld for reverse flow through a lossy link, and only the loading when no optimised capacity is available.
