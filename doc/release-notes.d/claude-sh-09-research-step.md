* Feat(pypsa-gui): Study harness research step. A harness run whose granted envelope allows research looks up the site's import tariff with the model provider's own web search and fetch, in research turns only (never in chat or a loop round). Each value is a source-ledger row with its url and a verbatim quote, checked by the server against the page fetched in that turn; a fabricated url or quote shows as an unverified source and is never offered. A value in another unit is refused. Every researched value waits for the user's Confirm or Reject on the research card; a confirmed tariff is then saved to the Library and attached, each on its own card even inside a granted envelope, and the other sources for that gap are rejected. A rejected value stays in the ledger. A provider without web search marks the step not available and lists the gap.
