* Feat(pypsa-gui): Site 3D native sites. Set the project's site coordinates in Project & site, create a 3D site from a numeric boundary (or draw it on the Satellite map), generate its buildings from mapped footprints and proposed rectangles, review the preview, then apply it or discard it, and correct a building's height or shape by numbers. The scene GET returns the Site's version while it is not yet a 3D scene, so the first Generate adopts it safely.
