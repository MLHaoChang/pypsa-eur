* Fix(pypsa-gui): Grid readiness no longer credits grid services to units behind a data centre's power architecture. Under a set architecture, the UPS and the units on a critical bus reach the grid only through that architecture, so "AC (LV UPS)" no longer passes frequency support on its UPS side. The scorecard row and the architecture compare name the unit each credited service comes from (DC grid-readiness walkthrough 03).

* Fix(pypsa-gui): The short-circuit ratio's inverter capacity is no longer a hidden template constant. Without a stated IBR capacity on the PoC bus, the SCR gate derives it from the network's converter-coupled assets (inverter-based generators and storage, not those behind the UPS), so added battery strings lower the SCR. The row states the capacity and its source, and says when a stated capacity is below the converters the network now holds (DC grid-readiness walkthrough 05).
