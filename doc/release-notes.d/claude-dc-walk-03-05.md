* Fix(pypsa-gui): Grid readiness no longer credits grid services to units behind a data centre's power architecture. Under a set architecture, the UPS and the units on a critical bus reach the grid only through that architecture, so "AC (LV UPS)" no longer passes frequency support on its UPS side. Under a set architecture, the scorecard row and the architecture compare name the unit each credited service comes from. With no architecture set, the compare reads the same frequency support as the scorecard. The compare's voltage-control cell lists only voltage control (DC grid-readiness walkthrough 03).

* Fix(pypsa-gui): The short-circuit ratio's inverter capacity is no longer a hidden template constant. Without a stated IBR capacity on the PoC bus, the SCR gate derives it from the network's converter-coupled assets (inverter-based generators and storage, not those behind the UPS), so added battery strings lower the SCR. The row states the capacity and its source, and says when a stated capacity is below the converters the network now holds. Such a stated capacity, or a derived one with an unsized converter, at any point of connection reads Unknown instead of Pass. The Energy Hub study's SCR gate and its readiness check derive the capacity the same way, and withhold the Pass in the same cases: the gate reports it as not established and still gives the figure. They do not know the power architecture, so they also count the units behind it. New Data Center Energy Hub projects no longer state a 30 MVA inverter capacity and derive it instead; existing projects keep their stored value (DC grid-readiness walkthrough 05).
