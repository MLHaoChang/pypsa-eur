* Feat(pypsa-gui): a project template can ship price series (`project_templates/<id>/price_series/`, a `meta.json` and one CSV per series). Creating a project from it mints them into the creating organisation's Library (idempotent on content, labelled `illustrative` and UTC, with currency, price basis and region as notes until the series metadata has them) and writes the refs into the new project's commercial settings, which bind as before. A bad series refuses the create with a typed 422 before the project exists.
