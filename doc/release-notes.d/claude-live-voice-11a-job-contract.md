* Feat(pypsa-gui): The assistant's background jobs (foreground solves and AC power flows, adequacy, FMEA, Monte Carlo, frontier, coupling, margin, energy-hub, investment- and business-case studies, reports, and solve-queue jobs including GridSpine) now share one status view. It shows each job's status, phase, progress, a change cursor, timestamps, input and result revision, warnings and terminal outcome. A cancel by job handle stops exactly that job's own run (never a newer run that replaced it) and reports only what it verified: `cancelled` once the worker has exited, `cancel_requested` while it has not, `already_finished`, `finished_first`, `origin_lost` when a newer run has replaced the job (nothing is stopped), or `refused` with the reason the stop was refused. A job started without a recorded owner can be viewed but not cancelled. This is internal groundwork for live voice monitoring; no tool or screen changes yet.
