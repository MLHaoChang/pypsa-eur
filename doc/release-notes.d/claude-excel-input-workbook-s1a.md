* Feat(gridspine): Excel input workbook, reader and writer. `gridspine.ingest.excel_export.write_workbook` writes a project, or a blank template, as one workbook with plain-named sheets (Nodes, Lines, Transformers, Generators, Storage, Loads, Links, Time series, Horizon and finance). Units sit under the column names, cells have drop-down lists, and an About sheet explains the workbook. `gridspine.ingest.excel_import.read_excel` reads it back into the same network and sidecars. Every row, column or cell it cannot use is reported with the reason, never dropped.
