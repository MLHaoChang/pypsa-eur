# The 220/110 kV campus transformers' impedance and losses have no public source

Status: needs-info
Type: task
Blocked by: None

Filed by campus-library-gaps 01 (GK A, CL-01 plan GO, 2026-11-06).

## What was seen

The five 220/110 kV units in `gridspine/templates/data/campus_assets.yaml` (TR_220_110_125/160/200/250/315)
take their cost from cited Ei rows (R-NR-T-8-1..5; 125 and 160 MVA interpolated between them). Their `vkr_percent` (0.3), `pfe_kw` (1 kW per MVA) and
`i0_percent` (0.1) come from `producers/campus.py`'s class rule, tagged `assumed` with the note "no public
source; producers/campus.py class rule". `vk_percent` (12.5) is IEC 60076-5:2006 Table 1's minimum for
more than 100 MVA, not a typical value. No manufacturer datasheet with 220/110 kV losses was found.

## What to do

1. Read the EU Ecodesign Tier 2 minimum Peak Efficiency Index for liquid-immersed large power
   transformers (Commission Regulation (EU) No 548/2014, as amended by (EU) 2019/1783, Annex I) at 125-315
   MVA. EUR-Lex returned an empty 202 to the CL-01 session's container.
2. Check that each unit's class-rule losses meet that bound. PEI = 1 - 2(P0 + Pc0) / (Sr sqrt((P0 + Pc0) / Pk)),
   with P0 = `pfe_kw`, Pk from `vkr_percent` x Sr, and Pc0 = 0.
3. If a public datasheet or standard gives a split of no-load and load loss at these ratings, propose it
   as a reviewed change. A new value changes the library's sha256, so it needs a new defaults pack version.

## Done

The bound is checked and recorded here (pass, or a NOT OK naming the unit), and any sourced replacement
is merged or filed.
