# Broader reliability calibration and domain review

The user requested these remaining scopes after the approved five-case live
run. This implementation expands reproducible numerical coverage and supplies
an offline independent-review/calibration workflow. It does not invent reviewers,
user-population observations or additional paid-call authorization.

Require the existing 53 public-boundary cases plus eight numerical scenarios
across all five profiles, each with a valid golden and a corrupt draft/repair.
Keep independent input accounting separate from the production calculation
services. Include zero/fractional loads, distinct energy/objective weights,
changing prices, different fixed charges and storage efficiencies. Every valid
golden must fulfill all requested slots; zero false acceptance/calculation errors
or unchecked publication is mandatory. CI uses the expanded gate.

Prepare a blind ten-interpretation packet and forty worked numerical oracles.
Two distinct independently attested domain reviewers must supply agreeing labels
for every interpretation. Missing, unresolved and disputed labels remain open;
missing model observations and provider errors cannot disappear from completion
criteria. Reconcile labels against exact packet hashes, never test-authored
labels presented as human judgments. Imported documents are evaluation data.

Measure false acceptance and false rejection separately, alongside withholding,
label resolution and observation completion. Zero denominators have null rates.
Synthetic judgments never create population estimates or statistical intervals.
Only a complete externally attested representative IID sample may have Wilson
95% intervals; identity, sampling and label accuracy require external verification.
No offline report can grant runtime publication authority or domain approval.

Independent expert review and representative observation collection remain
required inputs. The pending review package is a concrete handoff, not a passed
review. See the [runbook](calibration-runbook.md).
