# Bounded pilot evaluation gate

The user approved this scope on 2026-10-12: independent numerical expectations,
realistic requests for all five existing profiles, adversarial failures and a
repeatable report that refuses release on missing coverage or failed behavior.
This extends P7; it does not close whole-domain release or confer independent
engineering approval. Runtime deployment defaults remain unchanged.

The versioned catalogue covers every default metric with positive fulfillment,
plus wrong value, unit, formula, source, incomplete draft, invented narrative,
stale solve, missing raw dispatch and unsupported requested metrics. Cost
profiles also require explicit basis clarification. Golden requests use the
existing whole-message grammar, rather than client-injected scope. Adversarial
typed scopes exercise the same public authenticated strict stream and owned
answer retrieval. The expected values are hand-worked independently of the
calculation services; the solver is used to construct their raw trajectories.

Report counts and denominators for false acceptance, calculation errors,
false rejection, fulfillment, unavailable slots and unchecked publication.
Require all catalogue IDs exactly once, no skips/errors, all valid golden slots
fulfilled and zero deterministic false accepts or unchecked publication.
Explicitly distinguish deterministic scripted model output from optional live
generation. Missing live evaluation remains pending, not a production estimate.

Live runs are an explicit CLI opt-in, isolated from user projects and credentials
on disk. Reserve every HTTP attempt (including adaptive retries) before send,
with fixed request, serialized input-byte, output-token and wall-time ceilings.
These are resource caps, not a quoted dollar-spend guarantee. Reports contain
only bounded case IDs, reason codes, counts and source/model/version metadata;
never raw model output, prompts, credential hints, HTTP headers or exceptions.

The standalone gate exits nonzero on collection failure, skip, missing case,
timeout, scoring failure or inability to save the report. A passed deterministic
gate is only a finite-suite result. Broader browser/voice/artifact journeys,
domain review, population error estimates and production enablement stay open.
