# Publication evidence scope

These JSON files retain the repository/source observations, tree/test-presence signals and pinned source identities used in the research. They are observations, not executed tests.

Raw third-party README, source-code, licence-text and native-source cache copies remain in the original local research workspace; they are not republished here. Follow the pinned upstream links and retain the applicable notices if retrieving them. The source collection helpers regenerate their own local caches using authenticated GitHub access; they are not run during publication. `native-source-manifest.json` hashes the original local snapshots, whose copied bytes are not included in this publication.
