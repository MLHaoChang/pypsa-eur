# App walk of the templates, 2026-11-17

The project was created from the wizard, then every Guided section was walked, each Edit / Open-here drawer was opened, and the Expert property panel was read for the picked components. Probe scripts: the session scratchpad `probe/walk.mjs`, `walksite.mjs`, `props.mjs`.

## The probe fix (for the Playwright journeys)

- Symptom: after the project was created, `getByTestId('hub-design-panel')` never appeared, so every section errored.
- Cause: before each rail click the probe pressed `Escape` to close a leftover drawer. Escape now closes the whole Hub design panel (the `Close ×` at the top right), so the rail and the panel were gone. Creation, the route and the Guided button were all fine.
- Fix: never press Escape while no dialog is open. Use `ensurePanel()`, which reopens the panel through `getByTestId('sidebar-hub-design')` (after clicking Guided if needed), before every rail click and after every drawer. Close drawers with `field-drawer-close`, and press Escape only when a dialog is open. An Edit that jumped to Expert is detected as "panel not visible and no dialog", and the probe clicks Guided to come back.
- Site form: the radios are `sr-only`, so `input.check()` times out. Click the label `getByTestId('site-type-<id>')` instead. Creating a site whose name already exists ("A project named … already exists, so nothing was created") needs a delete by API and a retry. Read the project name from the "Created '…'" text after `site-create`.
