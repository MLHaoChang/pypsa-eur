## What happens

1. Generate the study report (MC LOLE 3.21 h/yr in the `headline` table) and export
   its DOCX.
2. In Word, change the headline cell "MC LOLE (h/yr)" to "1.00 h/yr".
3. `import_edited_report(report_id, file_id)`, with `bind_as_template` false or true.

Version 2's `executive_summary` becomes `source: user_edit`, and its `headline`
TableRef is replaced by `headline_edited_v2`. The exported v2 DOCX headline then reads
"1.00 h/yr", with no "Numbers to check" entry and no audit. `get_report_table(rid,
"headline")` still reads 3.21, and v1 is intact.

## The bypass

The roundtrip's edited-table path (`services/reports/roundtrip.py`, a table becomes
`<id>_edited_v<next>` in `edited_tables`) never goes through
`services/reports/revisions.py::_number_reason`. That is the check that stops a
regenerated or comment-anchored edit from changing an evidence-bound number.

The same holds for a number edited in a section's prose: "The plan meets 3.2 h/yr." edited
to "The plan meets 1.0 h/yr." is stored as `user_edit` with no audit entry. The LC-43 fixture
therefore edits the prose to a sentence without a number.

## Done when

An imported table or prose edit that changes an evidence-bound number either is refused or
is listed in "Numbers to check" (unverified, withheld from the headline), under both
`bind_as_template` values. A test pins that, and `LC-D21.edited_admitted_number` in
`pypsa-gui/backend/smoke/family_manifest.py` turns covered.

Prose with a changed number stays as written and is listed as unverified, not withheld.

**Plan GO conditions, GK B (52)** (option 1; recorded here per GK B (54)). The plan was built under these:
- **T1, per-cell compare:** an edited table is compared with its original cell by cell, never as one multiset, so two rows that swap values are a change.
- **T2, units count:** a unit changed beside a number, in a row label, a column header (corner header included) or a separate Unit column is a change.
- **T3, exact compare:** numbers are compared exactly by value and unit (`revisions.numbers()`), so 3.2149 vs 3.21 is a change and a numerically equal reformat (3.210, 1,000, a Unicode minus) is not.
- **T4, prose re-audit:** a changed section's prose is re-audited against the facts the base verified (`revisions.rerun_audit`).
- **T5, mutants:** `scripts/coord/mutants.py` runs on the changed lines of `roundtrip.py` and `revisions.py`; the PR body lists every survivor and why it is equivalent.

**GK B (54) NOT OK fixes 2026-11-13** (#1471). Edited tables pair with the section's tables by content (`_pair`), not position (D1); a unit edit in the corner header or a Unit column counts (D2, D3); duplicated row labels pair with nothing (D4); prose a withheld section cannot verify becomes the withheld placeholder and is listed in the appendix (D5). Killing tests for each, and for M1b and M2, are in `tests/test_lc43_d21_report_gates.py`.
